# Security Gate — GRIT Control Center

1. CI e build verdes antes de merge.
2. RLS ativa em tabelas de leads/atividades.
3. Nenhum segredo no frontend.
4. Acesso administrativo validado por `admin_users`.
5. Auditabilidade de estágio, responsável e próxima ação.
6. Deploy com marcador de release verificável.
7. Smoke test de `/admin`, `/admin/apps` e `/admin/apps/leads`.
8. Revisão periódica de usuários administrativos e permissões.
