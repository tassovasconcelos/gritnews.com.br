# Validação do modo suporte

1. No Super Admin, abrir **Clientes** e selecionar o cliente desejado.
2. Clicar em **Abrir operação com suporte auditado**.
3. Confirmar que o `support_tenant` da URL corresponde ao cliente selecionado.
4. Confirmar que o cabeçalho/banner mostra o mesmo cliente.
5. Confirmar que não aparece cobrança de setup, assinatura ou trial para o Super Admin.
6. Confirmar que o cliente comum continua sujeito aos bloqueios comerciais normais.
