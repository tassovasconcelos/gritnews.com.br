# Super Admin — Fase 2

Objetivo: transformar Clientes 360º em uma central ativa de retenção e expansão da base.

## Entregas desta fase

- filtros de saúde e situação para priorizar a carteira;
- resumo rápido da base por risco, atenção, saudável e excelente;
- identificação visual de clientes sem movimento recente;
- ações comerciais de WhatsApp com mensagens contextuais;
- estrutura preparada para timeline, notas internas e campanhas segmentadas na próxima migration.

## Critérios

- nenhum dado fictício no admin;
- métricas vêm do Supabase;
- ações críticas continuam auditadas no banco;
- GitHub `main` continua sendo a fonte única para publicação via integração nativa Hostinger.
